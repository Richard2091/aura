# 开发路线图

## 阶段总览

| 阶段 | 目标 | 关键交付 |
|---|---|---|
| **M0 - 骨架** | 建立项目与抽象 | 核心循环、传感器接口、模型抽象、文档 |
| **M1 - 可沉默循环** | 验证「想完可不说话」 | 纯文本 demo，无真实感知 |
| **M2 - 读屏感知** | 接入第一个真实环境源 | 读屏 OCR → 世界状态 → 循环 |
| **M3 - 本地模型** | 全本地推理 | Ollama/VLM 接入 |
| **M4 - 内在动机** | 更自主的决策 | 环境变化检测 / 好奇心驱动 |
| **M5 - 多源 & 语音** | 多视频源 + 语音 | 摄像头、ASR/TTS |
| **M6 - 持续记忆/世界模型** | 更强的世界认知 | 跨时间记忆、预测模型 |

## 里程碑验收标准

- **M1**：Agent 在无人类提示下自主运行 ≥ N 轮，至少出现一次「选择不说话」。
- **M2**：能给出一条关于当前屏幕的实际、非空描述。
- **M3**：全程本地推理（无外网），往返延迟可控。
- **M5**：能同时接入 ≥2 路视频源，且不阻塞核心循环。
