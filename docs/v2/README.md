## 跟 v1 相比，变了什么

v1 的循环是"感知 → 大模型思考 → 大模型决策 → 行动或沉默"，**每一轮都要调用两次大模型**。

v2 改成：

```
感知 → 决策模型（快、便宜、一直在跑）→ 需要时才调用大模型思考 → 按轻重等断点表达 / 记在心里 / 以后再行动
```

- 新增**决策模型**：负责判断"值不值得想、怎么回应、大概方向、现在适不适合打扰"。
- 大模型只在需要时出场，而且可以**弃权**（想完觉得没必要就不说）。
- 感知从"定时截全屏 + OCR"改成**插件式、事件驱动**：ActivityWatch、UIA 文字、键鼠活动、截图等感知源共用一条处理管线，输出带结构化数据的事件。
- **等断点再说，表达分轻重**：大部分想法只在托盘和客户端里轻轻提示；重要的才弹通知，而且等你告一段落。
- 三个接入点可插拔：**感知源、模型后端、动作工具**。
- 目标从"可以沉默的 Agent"扩展为**有内心活动、能读懂你、越用越懂你的 AI**。
