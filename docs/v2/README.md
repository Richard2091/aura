## 本次要交付什么

一个可在本人 Windows 电脑试用的主动助手实验原型：在至少两类应用获取正文与活动信号，经本地模型判断，需要时准备具体建议，等合适时机表达并记录反馈。不会自动操作软件、发消息、付钱或训练长期用户模型。

## 与 v1 的变化

```text
v1：定时感知 → 大模型思考 → 大模型决策 → 行动或沉默
v2：变化事件 → 合并/限流 → 本地快速判断 → 按需思考/弃权 → 等时机表达 → 反馈
```

决策模型可以常驻，但无事件时不推理；感知持续运行不等于持续调用模型。首版使用手写小抄和 JSONL，反馈用于评估与人工调参，尚不代表自动学习。

## 实施顺序

先 S0 小验证，同时搭 M0 合成回放与控制状态机；M1 打通真实输入、真实模型和具体建议；M2 用影子运行、正常试用及隔离评估报告证明有用且克制。Fake 回放展示控制逻辑，真实模型评估验证判断质量，两类成绩分开报告。

后续方向仍包括个性化记忆、内心活动、行动和多模态，但分别立项。v1 的 [总体架构](../architecture.md)、[循环](../agent-loop.md)、[感知方案](../environment-perception.md)、[本地模型](../local-model.md)、[路线](../roadmap.md) 保留为历史参考。
